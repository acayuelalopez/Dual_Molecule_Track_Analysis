# Dual-molecule Track Analysis

This repository contains a Python-based pipeline for the analysis of dual-molecule TIRF microscopy data. The script identifies and quantitatively analyzes spatially and temporally associated single-particle trajectories detected in two spectrally distinct fluorescence channels.

The pipeline uses as input the CSV outputs generated by a single-molecule TIRF tracking workflow and classifies trajectories as overlapping or non-overlapping based on spatial proximity and temporal overlap. It was developed to quantify dual-molecule association, co-trafficking, and membrane mobility from time-lapse TIRF microscopy experiments.

---

## Overview

Single-molecule TIRF microscopy experiments are typically analyzed independently for each fluorescence channel. However, many biological questions require identifying particles that move together over time, reflecting molecular association or coordinated behavior.

This pipeline performs a joint analysis of trajectories obtained from two fluorescence channels by:
- Filtering trajectories independently in each channel based on background-corrected intensity.
- Comparing trajectories frame by frame across channels.
- Identifying spatially and temporally associated trajectories.
- Classifying trajectories as overlapping (dual-molecule) or non-overlapping.
- Quantifying intensity- and mobility-related parameters for each population.

---

## Input data

The script requires as input the CSV files generated by a single-molecule TIRF tracking pipeline for each fluorescence channel.

For each image or field of view, the input directory should contain:
- Spot-level statistics CSV files.
- Track-level statistics CSV files.
- Corresponding files for both fluorescence channels.

The input CSV files are expected to include trajectory identifiers, frame numbers, particle positions, and intensity measurements. Typical columns include:
- `TRACK_ID`
- `FRAME`
- x/y coordinates
- `MEAN_INTENSITY_CH1`
- `Intensity-Bg Subtract` or `Spot Intensity-Bg Subtract`

Only images for which valid tracking files are available for both channels are processed.

---

## Analysis workflow

1. **File detection**  
   The script scans the input directory and identifies compatible spot-level and track-level CSV files for both channels.

2. **Trajectory sorting**  
   Trajectories are sorted by frame number to ensure consistent frame-wise comparisons.

3. **Intensity-based filtering**  
   For each trajectory, the mean background-corrected intensity is calculated over a user-defined frame range. Trajectories below the defined threshold are excluded. This step is performed independently for each channel.

4. **Dual-molecule trajectory pairing**  
   Filtered trajectories from both channels are compared frame by frame. Two trajectories are considered associated if they:
   - Overlap temporally for a minimum number of frames.
   - Remain within user-defined x/y distance thresholds.
   - Satisfy the allowed frame-gap constraint.

5. **Trajectory classification**  
   - Overlapping trajectories: paired trajectories detected in both channels.
   - Non-overlapping trajectories: trajectories detected in only one channel.

6. **Quantitative analysis**  
   For both populations, the script quantifies:
   - Track counts.
   - Background-corrected intensities.
   - Mean squared displacement (MSD)-derived parameters.
   - Apparent diffusion behavior.
   - Motion descriptors based on moment scaling spectrum (MSS / sMSS).

7. **Summary generation**  
   Per-image and global summary CSV files are generated for downstream statistical analysis.

## Installation

### Requirements

- Python ≥ 3.8

### Required Python packages

The pipeline requires the following Python packages:
- `numpy`
- `pandas`
- `matplotlib`
- `scikit-image`
- `pillow`

### Install Dependecies
```bash
pip install numpy pandas matplotlib scikit-image pillow
```

### Clone the repository

```bash
git clone https://github.com/USERNAME/dual-molecule-TIRF-analysis.git
cd dual-molecule-TIRF-analysis
```

---

## Running the analysis
- Run the script from the command line:
```bash
python dualTIRF_modified_skip.py
```
- The script is interactive and will prompt the user to define all analysis parameters at runtime.
- Press Enter to accept the default value for any parameter.
  ### Analysis parameters
  The main parameters defined at runtime include:

  - Input directory containing the tracking CSV files.
  - Spatial distance thresholds in x and y.
  - Minimum number of overlapping frames.
  - Maximum allowed frame gap.
  - Frame range used for intensity-based filtering.
  - Background-corrected intensity thresholds for each channel.
  - Track length threshold.
  - Motility threshold based on diffusion-related metrics.

  **These parameters allow adaptation of the analysis to different experimental conditions and datasets.**
  
  ### Output structure
  - The script generates a results directory within the input directory:
  ```bash
  results_dualTIRFM/
 ```
